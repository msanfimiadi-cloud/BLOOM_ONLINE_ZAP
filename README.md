# BLOOM ONLINE ZAP

Собственный сервис онлайн-записи к партнёрам Bloom Club: маникюр, массаж, SPA, косметология и другие услуги.

## Первая рабочая версия

- Публичный каталог партнёров и индивидуальные страницы записи `/book/<slug>`.
- Выбор услуги, специалиста, даты и свободного времени.
- Расчёт свободных интервалов с учётом продолжительности услуги и рабочего графика.
- Защита от двойной записи и пересекающихся интервалов на стороне сервера.
- Подтверждение записи с адресом, специалистом, стоимостью и временем визита.
- Защищённый кабинет администратора `/dashboard`.
- Управление партнёрами, специалистами и услугами.
- Журнал визитов, статусы записей, фильтрация по партнёру и сводная статистика.
- Постоянное хранение организаций, услуг, специалистов и записей в Cloudflare D1.
- Адаптивный русскоязычный интерфейс.
- Разделение ролей владельца и партнёров с серверной проверкой каждой операции.
- Выдача и отключение партнёрских доступов по подтверждённому email.
- Telegram-уведомления о новых записях, отменах и изменениях статуса.
- Журнал отправки уведомлений и тестовые сообщения.
- Настраиваемая привилегия Bloom Club и часовой пояс каждого партнёра.
- Отдельные ссылки и HTML-кнопки для карточек партнёров Bloom Club.
- Автоматический учёт клиентов, пришедших по клубной ссылке.
- Полноценный календарь записей с колонками специалистов.
- Ручное создание, перенос и самостоятельная отмена записей.
- Автоматический расчёт скидки для посетителей Bloom Club.
- Рабочие дни, перерывы, интервалы между клиентами, выходные и исключения.
- Привязка конкретных услуг к специалистам.
- Карточки клиентов, история визитов, заметки и стоп-лист.
- Редактирование и отключение партнёров, специалистов и услуг.
- Защита от записи на прошедшее время с учётом часового пояса.
- Ограничение частоты публичных записей и защита от спама.
- Безопасная персональная ссылка для отмены клиентской записи.

## Технологии

React 19, Next-compatible Vinext, TypeScript, Cloudflare Workers, Cloudflare D1 и Drizzle ORM. Репозиторий не привязан к OpenAI Sites или другому чужому хостингу.

## Запуск

Требуется Node.js версии 22.13 или новее.

```bash
npm ci
npm run dev
```

Проверки:

```bash
npm run typecheck
npm test
npm run build
```

После изменения структуры базы данных:

```bash
npm run db:generate
```

Схема базы находится в `db/schema.ts`, миграции — в `drizzle/`, независимая конфигурация Cloudflare — в `wrangler.jsonc`.

## Развёртывание на своём Cloudflare

1. Выполните `npx wrangler login` и создайте D1-базу: `npx wrangler d1 create bloom-online-db`.
2. Вставьте выданный `database_id` вместо временного нулевого значения в `wrangler.jsonc`.
3. Примените миграции: `npm run db:migrate:remote`.
4. Задайте секреты через `npx wrangler secret put`: `OWNER_EMAIL`, `TELEGRAM_BOT_TOKEN`, `BLOOM_CLUB_API_URL` и `BLOOM_ONLINE_API_TOKEN`.
5. Опубликуйте проект командой `npm run deploy`, затем подключите собственный домен в Cloudflare Workers.

## Telegram-уведомления

Создайте бота через `@BotFather`, добавьте переменную окружения `TELEGRAM_BOT_TOKEN` в настройки сервера и укажите Telegram chat ID в кабинете партнёра. После сохранения можно отправить тестовое уведомление.

Дополнительная переменная `OWNER_EMAIL` позволяет заранее закрепить email владельца. Если она не задана, первым владельцем становится первый подтверждённый пользователь закрытого сайта.

## Интеграция с Bloom Club

Bloom Online подключается к основному приложению Bloom Club через защищённый server-to-server API.

1. В карточке партнёра Bloom Club укажите ссылку вида `https://ваш-домен/book/luna-studio`.
2. Участница нажимает «Записаться онлайн». Bloom Club выпускает короткоживущий подписанный токен, не содержащий имя или телефон.
3. Bloom Online проверяет токен на сервере Bloom Club, получает актуальное состояние подписки и заполняет имя с телефоном.
4. Клубная скидка применяется только после повторной серверной проверки действующей подписки и совпадения телефона.

Переменные окружения Bloom Online:

```text
BLOOM_CLUB_API_URL=https://bloomclub.ru/api/v1
BLOOM_ONLINE_API_TOKEN=одинаковый-секретный-ключ-не-короче-32-символов
```

На сервере Bloom Club задайте тот же `BLOOM_ONLINE_API_TOKEN` и `BLOOM_ONLINE_PUBLIC_URL` с текущим адресом сервиса записи. После смены домена достаточно обновить URL в настройках обоих проектов. Без настроенного API записи доступны, но клубная скидка по простой ссылке не применяется.

Каждый клубный переход ограничен конкретным партнёром: токен другой карточки нельзя применить для получения скидки. После создания, переноса, отмены, завершения или неявки Bloom Online отправляет защищённое событие на `POST /api/v1/booking/events`; Bloom Club сохраняет его в аналитике соответствующей участницы и партнёра. Общий секрет никогда не передаётся браузеру.

## Подготовка к запуску

1. Замените демонстрационные организации реальными партнёрами или отключите их в административном кабинете.
2. Задайте `OWNER_EMAIL`, прежде чем открывать сайт широкой аудитории.
3. Подключите `TELEGRAM_BOT_TOKEN`, если требуются уведомления.
4. Выдайте партнёрам доступ по email и настройте разрешения хостинга.
5. Подключите приобретённый домен и настройте его DNS-записи.
6. Настройте `BLOOM_CLUB_API_URL`, общий `BLOOM_ONLINE_API_TOKEN` и `BLOOM_ONLINE_PUBLIC_URL` на сервере клуба.
7. Разместите партнёрские ссылки в карточках Bloom Club.

Онлайн-оплата и предоплата требуют отдельных учётных данных и подключения соответствующих платёжных систем.
